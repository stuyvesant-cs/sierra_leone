# Curriculum Materials for CS @ Sierra Leone

Below is the list of topics covered in the SSS1 (intro level) curriculum by term.

## Term 1
### Learning the Basics of Computer
- Computer development
- History behind computer
- Types of computers
- Understand the difference between computer hardware and software

### Computer Systems
- Computer hardware systems
- Power Supply
- Overview on different operating systems
- Application software
- Concept of computing, data and information
- viewing information on Internet (the web)
- sending mails, using internet banking services

### Word Processing
- Working with word documents
- Understanding the basics of word processing
- Creating document
- Editing document
- Formatting
- Doing spell check
- Preview and print documents
- Mail merge
- Learn how to merge mailing lists with letters or documents

## Term 2
### Understanding Presentation
- Using presentation default template
- Understanding presentation views
- Good practice in creating slide contents
- Formatting text

### Manipulation of Objects
- Understanding lists and tables
- Understanding charts
- Manipulation of objects
- Understanding
- grouping and arrangement
- Presentations slide transitions

### Animation
- Animation effects
- Hide show slides
- Spell check
- Print
- Slide show

## Term 3
### Introduction to Internet
- WWW and Web browsers
- Basic of computer networks
- LAN, WAN; concept of internet
- Applications of internet
- Connecting to internet
- internet service providers (ISP)
- Knowing the Internet
- Basics of internet connectivity related troubleshooting

### World Wide Web (WWW)
- World Wide Web; Web browsing software
- Search engines
- Understanding URL
- Domain name IP address
- Using governance website

### Understanding Databases
- Introduction to spreadsheets
- Open spreadsheet
- Understand glossary of terms using queries
- Common database tasks
- Using forms

### Reports
- Database reports
- Grouping reports
- Presenting specific fields
- Understand database reports, headers, and footers
- Learning how to export to spreadsheet or text
